## Correção de transporte

A primeira tentativa F2.9C, gate #287/run `33384509699`, falhou antes do executor:
o cliente Python `urllib` recebeu HTTP 401 ao seguir o redirect do download de
artifact. Nenhuma escrita ocorreu nessa tentativa.

A F2.9C.1 substituiu somente o transporte por GitHub CLI (`gh api` para validar
metadata e `gh run download` para obter o artifact), mantendo intacto o executor
e toda a cadeia criptográfica. A retry successful demonstrou que o problema era
instrumental e não do plano de backfill.
