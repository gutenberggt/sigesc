# Checklist de aceitação — Objetos de Conhecimento / Professor

- [ ] Acesso Rápido direciona para Meus Diários.
- [ ] Card Conteúdos abre URL com `assignment_id`.
- [ ] Histórico anterior ao DVD aparece e permanece somente leitura.
- [ ] Anos Iniciais mostram componentes irmãos do próprio professor.
- [ ] Novo lançamento multicomponente usa um assignment por componente.
- [ ] Edição de conteúdo canônico usa correção versionada quando publicado.
- [ ] Exclusão de conteúdo canônico continua auditada.
- [ ] Cópia para turma/componente com vínculo autorizado funciona.
- [ ] Cópia sem vínculo de destino é bloqueada.
- [ ] PDF de Anos Iniciais reúne componentes do próprio professor.
- [ ] PDF de Anos Finais permanece por componente/vínculo.
- [ ] Nenhuma escrita em `learning_objects`.
